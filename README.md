
# DcLink

A simple and customizable Discord integration plugin for Minecraft Paper servers.

## Features
- `/discord` – Display Discord information in chat.
- Clickable OPEN DISCORD button.
- COPY LINK button.
- Custom Discord message.
- Custom Discord invite link.
- Automatic Discord announcements.
- Custom announcement message and interval.
- Reload configuration without restarting the server.
- Minecraft color code support.

## Commands

| Command | Description |
|---|---|
| `/discord` | Show Discord information |
| `/discord msg set <message>` | Change Discord message |
| `/discord link set <link>` | Change Discord invite |
| `/discord anc set <message>` | Change announcement |
| `/discord anc time set <time>` | Set announcement interval |
| `/discord reload` | Reload configuration |

## Permission
- `dclink.admin` – Manage plugin settings (default: OP).

## Configuration
Edit `plugins/DcLink/config.yml` to customize messages, links and announcements.

## Compatibility
- Minecraft Paper 26.2
- Java 25
